# Екатеринбург: интересные отзывы

Бот собирает свежие отзывы заведений Екатеринбурга, находит интересные истории и диалоги с ответами заведений и публикует лучшие кандидаты в Telegram-канал.

## Архитектура

- `EkbReviews.Domain` — модели отзывов и кандидатов.
- `EkbReviews.Application` — контракты источников, анализатора и Telegram-публикатора; пока есть локальный эвристический анализатор.
- `EkbReviews.Worker` — фоновый процесс сбора/анализа/публикации.

Планируемые адаптеры источников: 2ГИС и Яндекс Карты. Для каждого источника используется отдельный адаптер, чтобы не связывать доменную модель с API конкретного сервиса.

## Следующие этапы

1. Подключить официальный/разрешённый способ получения отзывов 2ГИС.
2. Добавить хранение отзывов и fingerprint для дедупликации.
3. Подключить анализатор на базе LLM и ранжирование.
4. Добавить генерацию PNG-карточек диалогов через Playwright.
5. Подключить Telegram Bot API и расписание публикаций.
6. Добавить PostgreSQL, Docker Compose и небольшую админку для модерации.

До реализации парсеров проверяем актуальные условия использования источников: тексты отзывов и изображения нельзя автоматически публиковать без учёта правил соответствующего сервиса.
