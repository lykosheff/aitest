# Екатеринбург: интересные отзывы

Бот собирает свежие отзывы заведений Екатеринбурга, находит интересные истории и диалоги с ответами заведений и публикует лучшие кандидаты в Telegram-канал.

## Текущий этап

Первое звено реализовано: discovery заведений через официальный 2ГИС Places API.

- поиск заведений по запросу;
- `type=branch`;
- `has_reviews=true`;
- сортировка по рейтингу;
- до 50 результатов;
- конфигурация через `TwoGis:*`;
- периодический запуск worker каждые 30 минут.

Важный нюанс: актуальная документация 2ГИС указывает, что `has_reviews` позволяет найти объекты с отзывами, но получение самих отзывов через Places API не поддерживается. Поэтому сбор текстов отзывов будет отдельным адаптером через другой разрешённый источник/механизм.

## Архитектура

- `EkbReviews.Domain` — модели отзывов и кандидатов.
- `EkbReviews.Application` — контракты источников, анализатора и Telegram-публикатора.
- `EkbReviews.Infrastructure` — интеграции с внешними сервисами.
- `EkbReviews.Worker` — фоновый процесс.

## Конфигурация

API key задаётся через переменную окружения:

```bash
TwoGis__ApiKey=...
```
